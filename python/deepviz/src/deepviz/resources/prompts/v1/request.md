# Request template — v1

Use alongside `system.md`; replace only the bracketed values. Give a small schema
description, not a huge dataset. The reference is data, not executable syntax.

> Question: [business/scientific question].
> Goal: [comparison | trend | relationship | distribution | composition].
> Source reference: {"file": "[relative path approved by the host]"}.
> Known fields/units: [field names, types, units; note uncertainty].
> Required mapping/reduction: [explicit mapping and sum/mean/count/sample if known].
> Deliverable: [static PNG/SVG or interactive HTML], [light/dark], [title].
> Profile the source, review a recommendation, render, and report the artifact,
> input/output counts, strategy, and warnings without returning raw data.
